همراه تریدر — نسخه آزمایشی موبایل

محتویات:
- index.html: رابط فارسی آزمایشی
- manifest.json: مشخصات وب‌اپ قابل نصب
- sw.js: فایل پایه برای کش آفلاین

مهم:
این نسخه APK نیست و قیمت‌های آن ساختگی هستند. به بروکر یا منبع داده زنده وصل نیست و سفارش ارسال نمی‌کند.

برای آزمایش فوری:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) index.html را در مرورگر باز کنید؛ ممکن است بعضی قابلیت‌های نصب به دلیل نیاز به HTTPS کار نکنند.
3) برای نصب به شکل وب‌اپ (PWA)، فایل‌ها باید روی یک میزبانی HTTPS قرار گیرند و سپس از منوی Chrome گزینه «افزودن به صفحه اصلی» انتخاب شود.
4) برای APK واقعی، پروژه باید با ابزار ساخت اندروید یا سرویس build ابری بسته‌بندی و تست شود. هیچ کلید API یا رمز حساب را در این نمونه وارد نکنید.
